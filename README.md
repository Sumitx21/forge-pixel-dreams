# Pixel Forge Showcase

Create a short, polished website called PixelForge dedicated to pixel-art games.

Overall style

Dark retro-gaming aesthetic.

Pixel-art inspired UI without making the entire site look cluttered.

Use a dark navy/black background with bright pixel-inspired accent colors.

Use chunky retro-style headings and clean readable body text.

Add subtle scanlines, pixel patterns, glowing borders, and small hover animations.

Make the website fully responsive for desktop, tablet, and mobile.

Keep it visually impressive but relatively simple and lightweight.

Homepage

Create a single-page website with these sections:

1. Hero

Large heading:

PIXELFORGE

Subtitle:

Small pixels. Big adventures.

Short description:

"Discover the charm of pixel games — from nostalgic classics to modern indie adventures."

Add two buttons:

EXPLORE GAMES

LEARN MORE

Include a large pixel-art style illustration of a tiny adventurer standing in a colorful 16-bit landscape.

2. Featured Games

Create a grid of 4 game cards:

STARBOUND
"Explore strange worlds beyond the stars."

PIXEL KNIGHT
"Fight monsters, collect loot, become a legend."

NEON RUNNER
"Race through a futuristic pixel city."

FOREST TALES
"An enchanting adventure hidden among the trees."

Each card should have:

Pixel-art placeholder artwork

Game title

Short description

Genre tag

"VIEW GAME" button

3. Why Pixel Games?

Add a short section explaining:

"Pixel games prove that great games don't need cutting-edge graphics. With clever design, memorable characters, creative worlds, and beautiful pixel art, developers can create experiences that stay with players for years."

Show three small feature blocks:

NOSTALGIC — Classic visual style with modern ideas.

CREATIVE — Gameplay and imagination come first.

TIMELESS — Pixel art never truly goes out of style.

4. Footer

Display:

PIXELFORGE
"Made for people who still love pixels."

Add simple navigation links:
Home · Games · About · Contact

Extra details

Add smooth scrolling.

Add tasteful hover effects to buttons and game cards.

Add a subtle animated pixel/star background in the hero section.

Use placeholder images or generated pixel-art illustrations rather than copyrighted game artwork.

Do not add login, payments, database functionality, or unnecessary backend features.

The finished website should feel like a real indie gaming showcase rather than a generic template.
